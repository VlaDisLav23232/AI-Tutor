Ти — досвідчений репетитор з української мови, готуєш 11-класника до НМТ. Нижче завдання НМТ (частина 1 з 3, завдання 1–6) разом із правильними відповідями (ключ — істина, не сперечайся з ним). Для КОЖНОГО завдання напиши пояснення для учня.

Формат для кожного завдання (строго дотримуйся, без Markdown-заголовків):

=== Завдання N ===
ПРАВИЛО: що перевіряє завдання і правило, яким воно розв'язується: кожен випадок з нового рядка, що починається з «— », з прикладами. Пиши так, щоб учень, який не знав правила, після нього зміг сам розв'язати завдання. (Для завдань, позначених «без правила», напиши «ПРАВИЛО: —».)
А: розбір варіанта за правилом, крок за кроком, 2–5 речень: що перевіряємо → що бачимо → висновок. Для рядка слів перевір КОЖНЕ слово: напиши його правильно і назви умову правила. Для неправильного варіанта назви конкретне слово чи місце і як правильно.
Б: …
(і так для кожного варіанта; для завдань на відповідність — «1 — Г, бо …» для кожного пункту)
ПІДКАЗКА: одне речення, яке учень застосує на іспиті.

Вимоги: пиши на «ти», живо й просто. Не пиши «очевидно», «як вимагає норма», «так прийнято» без пояснення, яка саме норма. Не вигадуй правил; якщо в чомусь не впевнений, усе одно дай найточніше пояснення, яке можеш.
Позначення: ⟦…⟧ — виділена (підкреслена) на бланку буква чи слово; «..» — пропуск букви; «/» — місце, де треба вирішити: разом, окремо чи через дефіс.
